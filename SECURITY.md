# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.3     | ✅                 |
| < 2.3   | ❌                 |

## Reporting a Vulnerability

Use the **Security** tab on this repository to open a private report. Reports are reviewed when time allows; confirmed issues will be patched and released.

Please do not open public issues for security vulnerabilities.

## Scope

- The browser application (`com.buccaneer.browser`)
- Injected JavaScript assets (`app/src/main/assets/`)
- The GitHub Actions release pipeline

## Out of Scope

- Third-party websites and their content
- The Android/WebView platform itself
- Issues requiring physical access to a device
